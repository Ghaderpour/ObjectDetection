## Repository Contents

### Border.zip

This folder contains the shapefiles used in the study, including:

* Country boundaries
* Training circles (ground-truth stone cairns for the training region)
* Testing circles (ground-truth stone cairns for the testing region)

### GoogleSatClipped.zip

This folder contains the datasets and auxiliary files used for model training and evaluation, including:

1. **Google Satellite imagery**

   * Clipped Google Satellite images for the study area, training region, and testing region.

2. **YOLOTrainSet**

   * Training and validation image tiles and their corresponding labels generated by `YOLOInput.py`.

3. **Shapefile folders**

   * **TrainCircles** – Ground-truth stone cairns within the training region.
   * **TestCircles** – Ground-truth stone cairns within the testing region.
   * **PredictedBoxes** – YOLO-predicted bounding boxes for the testing region.
   * **PredictedCircles** – Circular representations of predicted stone cairns generated after DBSCAN clustering.

4. **YOLO configuration files**

   * `yolov8n.pt` – Pretrained YOLOv8n model weights.
   * `data.yaml` – Dataset configuration file used for YOLO training.

### runs-optimal.zip

This folder contains the training outputs and validation results obtained from the optimized YOLOv8n model.

## Python Scripts

### GoogleSatClip.py

Downloads the highest-resolution Google Satellite imagery, mosaics the image tiles, clips the mosaic to the input boundary shapefile, and exports the final RGB image as a GeoTIFF.

### YOLOInput.py

Generates training and validation image tiles and corresponding annotation files required for YOLO model training.

### YOLOTrain.py

Trains the YOLOv8 model using the training and validation datasets specified in `data.yaml`.

### YOLOOutput.py

Applies the best-performing trained YOLO model (`best.pt`) to a GeoTIFF image and predicts bounding boxes corresponding to stone cairns.

### YOLOBox2Circ.py

Converts YOLO-predicted bounding boxes into circular representations of stone cairns and performs DBSCAN-based clustering.

### CircRMSE.py

Evaluates model performance by comparing predicted and reference circles. The script computes the Root Mean Square Error (RMSE) and additional performance metrics, including precision, recall, and F1-score.
